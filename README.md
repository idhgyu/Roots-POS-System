# Roots POS Demo (Static)

This folder contains a single-page interactive demo.

## Files
- `index.html` — the app
- `B91CB7A8-4BB1-4364-9ED4-07DF64B9A40C.jpeg` — employee screen image
- `0A2D3799-B562-473C-9721-F096D1B95664.jpeg` — manager dashboard image

## Deploy options

### Netlify (drag-and-drop)
1. Go to https://app.netlify.com/drop
2. Drag this whole folder. Done.

### GitHub Pages
1. Create a new public repo.
2. Upload all files from this folder.
3. Settings → Pages → Deploy from branch, `main` (root).

### Vercel
1. Create new project and import the GitHub repo with these files, or use Deploy → Upload.

### Local preview
```bash
python -m http.server 8080
# open http://localhost:8080
```
